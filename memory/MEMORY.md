## Thesis
See soul/THESIS.md for the full framework.

Core frame: existing protocols — for how information moves, how organizations coordinate, how countries relate to their digital infrastructure — have gone morbid. The dominant response is individual adaptation. The real question is how to construct new coordination protocols from inside the wreckage. Everything in the hypotheses is an expression of this problem in a specific domain.

Active hypotheses: digital sovereignty as protocol construction, curated information diets as counter-infrastructure, AI nativeness as constraint recognition, agents as epistemic weapons, the generalist-operator, AI slop as organizational crisis.
